### 🌸 About me

I'm a 5th-semester **Computer Engineering** student at **CUCEI (Universidad de Guadalajara)**, working at the intersection of **cybersecurity and AI**.

- 🛡️ **Focus:** the security of AI agents — hardening them, and defending against agents used as attackers.
- 🔍 **Hands-on:** malware analysis, threat intelligence (IOCs, attack chains) and forensics; I practice on Hack The Box, TryHackMe and DockerLabs.
- 🤖 **ML:** Python for data analysis and machine learning; C++ and x86 assembly when performance or the hardware matters.
- 🧮 **Also into:** mathematics and cryptography, bioinformatics, and designing systems that fail safely.
- 🌍 **Languages:** Spanish (native) · English (C1) · German (B2)
